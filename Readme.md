## 1. Project Overview

This independent project explores vegetation patterns across Faisalabad District, Punjab, Pakistan, using Sentinel-2 satellite imagery and the Normalized Difference Vegetation Index (NDVI).

I developed this project using QGIS to process satellite imagery, calculate NDVI, prepare vegetation classification maps, and analyze NDVI class statistics. The project demonstrates my practical application of GIS and remote sensing techniques to agricultural monitoring.

As an Agronomy graduate from the University of Agriculture Faisalabad, I undertook this project to strengthen my technical skills in agricultural remote sensing, satellite-based vegetation analysis, and spatial data processing.

## 5. Methodology

1. Acquired Sentinel-2 imagery for the study area.
2. Selected the B04 Red and B08 Near-Infrared bands.
3. Calculated NDVI using the standard formula.
4. Clipped the NDVI raster to the Faisalabad District boundary.
5. Reprojected raster data to UTM Zone 43N where required.
6. Classified NDVI values into vegetation-index classes.
7. Prepared NDVI maps and summarized class statistics.
8. Organized the maps, processed datasets, reports, and QGIS project files for documentation and portfolio presentation.

## 6. NDVI Formula

NDVI = (B08 - B04) / (B08 + B04)

Where:

* **B08:** Near-Infrared reflectance.
* **B04:** Red reflectance.

NDVI values generally range from -1 to +1. Higher positive values often indicate greener vegetation, while values near zero or below zero may indicate bare surfaces, water, built-up areas, or other non-vegetated features.

NDVI interpretation depends on land cover, image conditions, and acquisition dates.

## 11. Limitations

NDVI indicates vegetation greenness but does not independently confirm crop yield, plant disease, or every aspect of crop health. Cloud contamination, image acquisition dates, land-cover differences, and classification thresholds can influence results.

Field observations and additional agricultural data would help validate and strengthen the interpretation.
