# Faisalabad Crop Health Monitoring Using Sentinel-2 and NDVI

**An Independent GIS & Remote Sensing Project**

### Project Author

Qasim Ali Shahid

Project Type: Independent Academic & Professional Portfolio Project
Study Area: Faisalabad District, Punjab, Pakistan

### About the Project

This independent project uses Sentinel-2 satellite imagery and the Normalized Difference Vegetation Index (NDVI) to assess vegetation patterns across Faisalabad District, Pakistan.

I developed this project using QGIS, applying remote sensing and spatial analysis techniques to produce NDVI maps, classified vegetation maps, and statistical summaries.

### Tools & Data

* QGIS
* Copernicus Sentinel-2 imagery (B04 and B08)
* NDVI analysis and raster processing

### Key Outputs

* Faisalabad NDVI Map
* Classified NDVI Map
* Processed raster datasets
* NDVI class statistics
* Project documentation and QGIS project file
